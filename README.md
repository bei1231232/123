# 理想国度

一个为吉客松路演制作的 16:9 横屏治愈系互动游戏 Demo。

## 体验路径

1. 梦境加载开场
2. 标题页点击「开始专注」
3. 选择「暖光集市」
4. 找到并点击 5 枚发光愿望
5. 解锁治愈结尾卡片

## 运行

直接双击 `index.html` 即可离线运行。

也可以在当前目录启动本地服务器：

```powershell
npx --yes serve .
```

然后访问终端输出的本地地址。

## 操作

- 鼠标：小鱼跟随指针，猫咪追逐小鱼
- 触屏：点击发光愿望并产生水波反馈
- 右上角：声音与全屏
- 竖屏手机：会提示旋转为横屏

## 美术替换

- 主背景：`assets/dream-kingdom.png`
- 原始风格参考：`assets/style-reference.jpg`
- 标题与「开始专注」当前为可替换文字，后续可改为透明 PNG
